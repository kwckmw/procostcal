# Kang's 원가 계산기

사장님용 '메뉴 원가 계산기' 웹앱을 만들어 주세요. 소상공인(카페·음식점) 사장님이 휴대폰으로 쓰는 앱입니다. 모든 화면 문구는 한국어입니다.

## 절대 규칙
- 데이터베이스, Lovable Cloud, Supabase, 로그인, 회원가입, 서버 함수를 쓰지 마세요. 모든 계산은 브라우저에서 하고 저장은 localStorage만 씁니다.
- 손님 개인정보를 받는 화면을 만들지 마세요.
- 모바일 우선. 375px 폭에서 가로 스크롤이 없어야 합니다. 표 대신 카드형 레이아웃을 쓰고, 숫자 입력칸은 inputmode="decimal"을 씁니다. 한국어 줄바꿈이 단어 중간에서 끊기지 않도록 전역에 word-break: keep-all을 넣어 주세요.
- 금액은 원 단위 정수로 반올림하고 천 단위 쉼표를 붙입니다(예: 1,234원). 퍼센트는 소수점 첫째 자리까지(예: 24.2%).
- 화면 상단에 항상 이 안내를 보여 주세요: "모든 기본값과 수수료는 예시입니다. 우리 가게 값과 내 계약 조건으로 바꾸세요." 그 옆이나 아래에 작게 "이 기기 브라우저에 자동 저장됨".

## 화면 구성 (하단 탭바 4개)
1. 재료: 재료를 한 번 등록하면 여러 메뉴에서 같이 씁니다. 재료 추가·수정·삭제.
   - 필드: 재료명, 구매 가격(원, 실제 낸 금액), 구매 용량, 단위(g·ml·개 세 가지만), 손실률(%, 선택, 기본 0)
   - 카드에 단위당 단가를 표시(예: 25원/g)
2. 메뉴: 메뉴 추가·수정·삭제. 메뉴마다 메뉴명, 판매가(원, 메뉴판 가격, 부가세 포함), 재료 행(재료 선택 + 사용량, 행 추가·삭제).
   - 각 메뉴 카드 바로 아래에 결과: 재료비, 원가율, 한 개 팔면 남는 돈, 목표 원가율 기준 권장 판매가.
   - 결과 아래에 '어떻게 계산했나요?' 접기 영역을 두고, 아래 공식에 실제 숫자를 넣어 풀어서 보여 주세요.
3. 시뮬레이션: 카드 2개.
   - 재료값 인상 카드: 인상률 슬라이더(0~30%, 기본 10). 메뉴별로 인상 후 원가율, 한 개당 줄어드는 돈, 한 달에 줄어드는 이익(한 개당 줄어든 돈 × 하루 판매량 × 월 영업일)을 보여 줍니다.
   - 할인 행사 카드: 메뉴 선택 + 할인율 슬라이더(0~50%, 기본 10). 할인 전·후 한 개 남는 돈과 "같은 이익을 남기려면 판매량을 ○○% 늘려야 해요"를 보여 줍니다. 할인 후 남는 돈이 0 이하이면 빨간 글씨로 "팔수록 손해예요".
4. 설정: 가게 이름, 과세 유형(라디오 3개), 목표 원가율 슬라이더(15~45%, 기본 30), 하루 판매량(개, 기본 50), 월 영업일(일, 기본 25), 'JSON 파일로 백업' 버튼, '백업 불러오기' 버튼, '예시 데이터로 초기화' 버튼.
   - 목표 원가율 슬라이더 옆 한 줄 설명: "부가세를 뺀 공급가 기준으로 계산합니다. 판매가 기준보다 약 2%p 엄격하게 나올 수 있어요."
   - 백업 버튼 옆 설명: "다른 기기로 옮기려면 백업 파일이 필요해요."

## 과세 유형 (설정에서 선택, 기본 일반과세자)
- 일반과세자: 매출 기준액 = 판매가 ÷ 1.1
- 간이과세자(납부): 매출 기준액 = 판매가 × 0.985 (음식점·카페는 업종 부가가치율 15% × 세율 10% = 1.5%)
- 간이과세자(연매출 4,800만 원 미만, 납부 면제): 매출 기준액 = 판매가 그대로

## 계산 공식
1. 단위당 단가 = 구매 가격 ÷ 구매 용량 ÷ (1 − 손실률/100)
2. 메뉴 재료비 = Σ(단위당 단가 × 사용량)
3. 원가율 = 메뉴 재료비 ÷ 매출 기준액 × 100
4. 한 개 팔면 남는 돈 = 매출 기준액 − 메뉴 재료비
5. 권장 판매가 = 메뉴 재료비 ÷ (목표 원가율/100) → 일반과세자는 × 1.1, 간이(납부)는 ÷ 0.985, 납부 면제는 그대로 → 100원 단위 올림
6. 재료값 인상 시 재료비 = 메뉴 재료비 × (1 + 인상률/100)
7. 할인 후 판매가 = 판매가 × (1 − 할인율/100). 할인 후 매출 기준액을 과세 유형대로 다시 계산. 필요한 판매량 증가율 = (할인 전 남는 돈 ÷ 할인 후 남는 돈 − 1) × 100

권장 판매가가 실제 판매가보다 낮게 나오면 메뉴 결과 아래에 작은 회색 글씨로 안내: "이 계산기는 재료비만 봅니다. 임대료·인건비도 감당해야 하니 권장가는 최소 기준으로만 참고하세요."

## 저장
- localStorage 키 하나(cost-calc-v1)에 재료·메뉴·설정을 JSON으로 저장. 입력할 때마다 자동 저장.
- 모든 localStorage 읽기·쓰기를 try/catch로 감싸 주세요. 시크릿 창처럼 저장이 막혀도 예시 데이터로 정상 동작해야 합니다.
- 처음 열 때(저장된 데이터가 없을 때) 아래 예시 데이터로 채워 주세요.
